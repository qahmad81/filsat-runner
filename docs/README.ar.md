# برنامج تشغيل فلسات على جهاز البائع

برنامج مستقل مفتوح المصدر لاستقبال طلبات خدماتك من فلسات وتنفيذها باستخدام Codex أو Claude Code أو OpenCode أو Pi أو DeepSeek Harness أو OpenRouter أو n8n.

1. اشترِ خدمة مكتملة من فلسات لتصبح مؤهلًا كتاجر، ثم أنشئ خدمتك عبر MCP بنوع `execution_kind=seller_local` وحدد الشروط ونوع الملفات والسعر والمهلة.
2. أنشئ رمزًا منفصلًا بصلاحية `runner:work` من إعدادات حسابك.
3. نزّل المستودع وثبته باستخدام Python 3.11 أو أحدث: `python -m pip install -e .`.
4. انسخ `config.example.json` إلى `runner.json`، واستبدل رقم الخدمة التجريبي برقم خدمتك. سجّل الدخول إلى أداة التنفيذ على جهازك؛ لا تُرسل بيانات دخول المزوّد إلى الموقع.
5. ضع رمز فلسات في متغير البيئة المحدد في الإعدادات ثم شغّل `python -m filsat_runner run --config runner.json`.

يتحقق البرنامج من الطلبات كل 30 ثانية. يدعم عدة خدمات و1–4 مهام متزامنة. لا يستخدم طلب العميل لتحديد أمر تيرمينال أو رابط n8n؛ هذه اختيارات يحددها البائع محليًا.

بعد تسجيل الدخول بالرمز، ينزّل البرنامج تعريفات الخدمات وجدول الدوام ويفحص جاهزية أدوات التنفيذ قبل إعلان الاتصال. الأخضر يعني أن الخدمة متصلة وتستقبل الطلبات، والبرتقالي أنها منقطعة خلال الدوام، والرمادي أنها خارج ساعات العمل. تنتهي الجاهزية بعد 90 ثانية دون اتصال. حدّد `work_schedule` بالأيام والمنطقة الزمنية ووقت البداية والنهاية؛ تساوي الوقتين يعني العمل 24 ساعة في الأيام المختارة. يتحمل البائع مسؤولية تشغيل جهازه وتوفر حساب المزوّد ورصيده. فحص جاهزية الوكلاء يرسل طلبًا قصيرًا فعليًا للمزوّد عند البداية ثم يخزّن النتيجة عشر دقائق، وقد يستهلك جزءًا صغيرًا من رصيد المزوّد.

يراجع الموقع الطلب قبل الخصم، ثم يعرض تأكيدًا للعميل. يعمل كل طلب في مجلد مؤقت جديد، وتُرسل النتائج المحددة فقط. يفحص الخادم الملفات قبل التسليم، وتظهر حالة التنفيذ الحقيقية ورابط تنزيل محمي بحساب العميل. يصل بريد عند اكتمال الطلب، وتُحفظ الملفات 30 يومًا. لا يضمن فحص الفيروسات خلو كل ملف من كل ضرر.

حصة التاجر 70% وحصة الموقع 30%، ويُضاف الإيراد إلى الرصيد الداخلي بعد نجاح التسليم. لا يوجد سحب خارجي حاليًا. عند انقطاع التنفيذ يُسترد الدفع من الرصيد، أما DOGE المباشر فيحتاج مراجعة استرداد. لا يعاد تنفيذ الطلب المنقطع تلقائيًا حتى لا تتكرر تكاليف المزوّد.

المجلد المؤقت ليس عزلًا أمنيًا. استخدم حساب نظام مخصصًا أو حاوية عند تشغيل الوكلاء، ولا تمنح طلب العميل صلاحية قراءة ملفاتك الشخصية. بعض أدوات CLI تحتاج إعداد صلاحيات مسبقًا، ولا يتجاوز البرنامج رفض الأذونات تلقائيًا.
